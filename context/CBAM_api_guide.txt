====================================================================================================
1. SUMMARY OF BACKEND CHANGES (CONTEXT FOR FRONTEND)
====================================================================================================
The backend has implemented the complete data models, calculation engines, catalog services, 
and Excel generation pipeline corresponding to the official EU CBAM Communication Template 
(specifically Sheet A_InstData and Sheet B_EmInst Section a):

1.1 NEW DATABASE MODELS & TABLES:
   - `cbam_aggregated_goods_categories`: 6 official CBAM aggregated sectors/categories (Crude steel, 
     Cement, Aluminium, Fertilizer, Chemicals, Hydrogen).
   - `cbam_cn_codes`: Official Combined Nomenclature (CN) 8-digit codes mapped to CBAM categories.
   - `cbam_installations`: Master profile of the industrial installation (location, UNLOCODE, verifier).
   - `cbam_installation_goods`: Produced Goods G1..G10 declared by the installation.
   - `cbam_production_processes`: Production processes P1..P10 defined at the site.
   - `cbam_purchased_precursors`: Purchased precursors PP1..PP20 sourced from external suppliers.
   - `cbam_source_streams`: Source streams (Slots 1..75) capturing Combustion and Mass Balance flows.

1.2 NEW ENUMS ADDED:
   - `CBAMSector`: 'CEMENT', 'ELECTRICITY', 'FERTILISERS', 'IRON_AND_STEEL', 'ALUMINIUM', 'CHEMICALS'
   - `CBAMStreamMethod`: 'Combustion', 'Mass balance'
   - `CBAMActivityUnit`: 't', '1000 Nm3'
   - `CBAMEmissionFactorUnit`: 'tCO2/TJ', 'tCO2/t', 'tCO2/1000Nm3'

1.3 DETERMINISTIC EMISSION CALCULATION ENGINE:
   - Automatic backend calculation of fossil CO2, biomass CO2, and energy content (TJ) upon stream 
     creation or update.
   - Pure EU CBAM stoichiometric factor 3.664 (44.01/12.011) applied for Mass Balance carbon streams.
   - Real-time preview calculation endpoint without saving to database (`/calculate-preview`).
   - Transaction commit fixes applied to guarantee persistence across all CRUD operations.

1.4 DEDICATED IPCC FUELS CATALOG ENDPOINT:
   - Added `GET /api/v1/tenant/cbam/catalog/ipcc-fuels` to allow frontend to easily search and populate 
     standard IPCC fallback emission factors for combustion fuels.

1.5 ZERO-CORRUPTION EXCEL GENERATION PIPELINE:
   - Native OpenXML exporter populates Sheet `A_InstData` and Sheet `B_EmInst` (Rows 17–91) while 
     preserving 100% of embedded formulas, calculation chains, conditional formatting, and macros.

6.2 POST /api/v1/tenant/cbam/installation/{installation_id}/source-streams
----------------------------------------------------------------------------------------------------
PURPOSE:
Create a new source stream. Automatically executes exact CBAM emission calculations and commits to PostgreSQL.

VARIATION REQUEST EXAMPLES COVERING ALL SCENARIOS:

SCENARIO 1: Combustion with NCV (GJ/t) and EF in tCO2/TJ
REQUEST:
{
  "method": "Combustion",
  "name": "Heavy fuel oil (Boiler 1)",
  "activity_data": 252000.0,
  "activity_unit": "t",
  "ncv": 45.0,
  "emission_factor": 73.0,
  "emission_factor_unit": "tCO2/TJ",
  "oxidation_factor": 100.0,
  "biomass_fraction": 0.0
}
RESPONSE:
- `fossil_co2_emissions`: 827820.0 t CO2  (252,000 * 45/1000 * 73.0)
- `energy_content_fossil_tj`: 11340.0 TJ  (252,000 * 45 / 1000)

SCENARIO 2: Combustion with EF in tCO2/t (Direct Fuel EF)
REQUEST:
{
  "method": "Combustion",
  "name": "Natural Gas (Furnace A)",
  "activity_data": 50000.0,
  "activity_unit": "t",
  "ncv": null,
  "emission_factor": 2.75,
  "emission_factor_unit": "tCO2/t",
  "oxidation_factor": 100.0,
  "biomass_fraction": 0.0
}
RESPONSE:
- `fossil_co2_emissions`: 137500.0 t CO2  (50,000 * 2.75)

SCENARIO 3: Combustion with Biomass Blend (e.g. 20% Biofuel)
REQUEST:
{
  "method": "Combustion",
  "name": "Bio-diesel Blend (Generator)",
  "activity_data": 10000.0,
  "activity_unit": "t",
  "ncv": 40.0,
  "emission_factor": 70.0,
  "emission_factor_unit": "tCO2/TJ",
  "oxidation_factor": 100.0,
  "biomass_fraction": 20.0
}
RESPONSE:
- `fossil_co2_emissions`: 22400.0 t CO2   (10,000 * 40/1000 * 70 * 0.80)
- `biomass_co2_emissions`: 5600.0 t CO2   (10,000 * 40/1000 * 70 * 0.20)
- `energy_content_fossil_tj`: 320.0 TJ
- `energy_content_bio_tj`: 80.0 TJ

SCENARIO 4: Combustion Fallback using IPCC Fuel ID
REQUEST:
{
  "method": "Combustion",

  "activity_unit": "t",

}
RESPONSE:
- Backend resolves IPCC factor and calculates emissions automatically.

SCENARIO 5: Mass Balance Input (e.g. Coal / Coke Input, Carbon Content)
REQUEST:
{
  "method": "Mass balance",
  "name": "Coking Coal Input",
  "activity_data": 50000.0,

====================================================================================================
7. MATHEMATICAL RULES & CALCULATION ENGINES
====================================================================================================

7.1 COMBUSTION METHODOLOGY:
   - Base Formula:
     Emissions = ActivityData * (NCV / 1000 if EF_Unit == 'tCO2/TJ' else 1) * EF * (OxidationFactor / 100)
   - Split:
     Fossil_CO2  = Emissions * (1 - BiomassFraction / 100)
     Biomass_CO2 = Emissions * (BiomassFraction / 100)
   - Energy Content:
     Fossil_Energy_TJ = ActivityData * (NCV / 1000) * (1 - BiomassFraction / 100)
     Bio_Energy_TJ    = ActivityData * (NCV / 1000) * (BiomassFraction / 100)

7.2 MASS BALANCE METHODOLOGY:
   - Stoichiometric constant = 3.664 (representing molecular ratio 44.01 / 12.011)
   - Base Formula:
     Emissions = ActivityData * CarbonContent * 3.664
   - Split:
     Fossil_CO2  = Emissions * (1 - BiomassFraction / 100)
     Biomass_CO2 = Emissions * (BiomassFraction / 100)
   - Rule on Direction:
     - Carbon Input Materials (e.g. coal, scrap, coke): `activity_data` > 0
     - Carbon Output Materials (e.g. crude steel, slag, export gas): `activity_data` < 0

7.3 SLOT NUMBERS (1 to 75):
   - The EU CBAM template Sheet `B_EmInst` provides exactly 75 rows (Rows 17 to 91).
   - If `slot_number` is omitted in POST, the backend auto-assigns the next free integer from 1 to 75.


====================================================================================================
8. FRONTEND STEP-BY-STEP USER JOURNEY
====================================================================================================

STEP 1: LOAD MASTER DATA & DROPDOWNS
   - Call `GET /catalog/categories` to populate Category options.
   - Call `GET /catalog/countries` to populate Country dropdown (e.g. 'Poland', 'India', 'Germany').
   - When user selects a category, call `GET /catalog/categories/{id}/routes` to populate Production Routes.
   - For guided CN code selection:
     1. `GET /catalog/categories/{id}/product-names` (Dropdown 2)
     2. `GET /catalog/categories/{id}/specifications?product_name=...` (Dropdown 3 -> selects CN Code)

STEP 2: CREATE / VIEW INSTALLATION PROFILE (Sheet A_InstData)
   - Form inputs: Site Name, Address, City, Country, UNLOCODE, Lat/Long, Authorized Rep, Verifier.
   - Goods Section: Assign Goods G1..G10 using selected category and routes.
   - Processes Section: Define Processes P1..P10 with target category and boundary mode.
   - Save via `POST /installation` or update via `PUT /installation/{id}`.

STEP 3: MANAGE SOURCE STREAMS (Sheet B_EmInst)
   - Call `GET /installation/{id}/source-streams` to render the source streams table.
   - Stream Add/Edit Modal:
     - Method radio: 'Combustion' vs 'Mass balance'
     - If Combustion:
       - Inputs: Stream Name, Activity Data (t or 1000 Nm3), NCV (GJ/t), Emission Factor & Unit ('tCO2/TJ' or 'tCO2/t'), Oxidation Factor % (default 100), Biomass % (default 0).
       - Optional Fallback button: "Select from Standard IPCC Fuels" -> opens searchable modal powered by `GET /catalog/ipcc-fuels`.
     - If Mass Balance:
       - Inputs: Stream Name, Activity Data (+ for input, - for output), Carbon Content (tC/t), Biomass %.
     - As user types, call `POST /installation/{id}/source-streams/calculate-preview` to display live calculated Fossil CO2 & Energy TJ in real time.
     - Submit via `POST /installation/{id}/source-streams` or `PUT /installation/{id}/source-streams/{stream_id}`.

STEP 4: SUMMARY & EXCEL DOWNLOAD
   - Call `GET /installation/{id}/source-streams/summary` to populate total direct emissions KPI cards.
   - Trigger Download button linking to `GET /installation/{id}/export-excel` to download the verified `.xlsx` file.


====================================================================================================
9. EDGE CASES, ERROR CODES & VALIDATION RULES
====================================================================================================

1. Missing NCV when EF is in tCO2/TJ:
   - Status: `400 Bad Request` or `422 Unprocessable Entity`
   - Message: "Net calorific value (NCV) is required when emission factor unit is tCO2/TJ."

2. Mass Balance Missing Carbon Content:
   - Status: `422 Unprocessable Entity`
   - Message: "Carbon content is required for Mass balance methodology."

3. Maximum Slot Limit Exceeded:
   - Status: `400 Bad Request`
   - Message: "Installation has reached the maximum capacity of 75 source stream slots in Sheet B_EmInst."

4. Invalid Production Route:
   - Status: `400 Bad Request`
   - Message: "Production route '{route}' is not a valid route for aggregated category '{category_name}'."

5. Boundary Mode DIRECT with Precursor IDs:
   - Validation Rule: When `boundary_mode` is 'DIRECT', `included_precursor_ids` should be empty `[]`.

6. Negative Activity Data for Combustion:
   - Validation Rule: Combustion fuels must have positive `activity_data` > 0.
