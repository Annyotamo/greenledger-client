1. GLOBAL RULES, CONVENTIONS & LIFECYCLE STATE MACHINE
===============================================================================

[A] AUTHENTICATION & HEADERS
- All endpoints require a valid JWT Bearer token in the request header:
  Authorization: Bearer <your_jwt_token>
- Requests with JSON bodies must include:
  Content-Type: application/json

[B] COMMON RESPONSE WRAPPER FORMAT
Every API response is wrapped in a standard structure:
{
  "success": true,
  "status_code": 200,
  "message": "Operation completed successfully",
  "data": { ... },
  "error": null,
  "method": "POST",
  "path": "/api/v1/tenant/scope3/...",
  "timestamp": "2026-08-20T12:00:00.000Z"
}

[C] REPORTING PERIOD FORMAT
- `reporting_period_id` is a UUID foreign key pointing to the tenant's registered `reporting_periods` record.
- In legacy spend endpoints, string labels (e.g. "FY 2021-22") are supported.

[D] ACTIVITY LIFECYCLE STATE MACHINE & IMMUTABILITY
- Status Values: "DRAFT", "SUBMITTED", "VERIFIED", "REJECTED".
- Standard User -> Defaults to "SUBMITTED" (or "DRAFT" if explicitly sent as "DRAFT").
- Immutability Rule:
  * Entries in state "VERIFIED" CANNOT be edited (`PUT`/`PATCH`) or deleted (`DELETE`) directly.
  * Attempting to edit/delete a verified entry returns HTTP 400 with error_code: "SCOPE3_ACTIVITY_IMMUTABLE".

2. SCOPE 3 CATEGORY 1: PURCHASED GOODS & SERVICES (SPEND-BASED)
===============================================================================

Description:
Captures purchase spend in INR across years (2020 to 2025), converts spend to USD
using annual average exchange rates, and calculates emissions using US EPA USEEIO
factors (kg CO2e per USD) with full margin breakdowns.

[A] ENDPOINTS
1. List Category 1 Spend Entries: GET /api/v1/tenant/scope3/category1/spend
2. Get Single Category 1 Entry: GET /api/v1/tenant/scope3/category1/spend/{activity_id}
3. Create Category 1 Spend Entry: POST /api/v1/tenant/scope3/category1/spend
4. Update Category 1 Entry: PATCH /api/v1/tenant/scope3/category1/spend/{activity_id}
5. Delete Category 1 Entry: DELETE /api/v1/tenant/scope3/category1/spend/{activity_id}

[B] SAMPLE CREATE REQUEST BODY
{
  "reporting_period": "FY 2021-22",
  "facility_id": null,
  "scope3_spend_emission_factor_id": "ca68b110-59ba-4c62-b841-270138cc06dd",
  "spend_date": "2021-12-09",
  "spend_in_inr": 45000.00,
  "spend_year": 2021,
  "notes": "Procurement spend for Soybean Farming (NAICS 111110)"
}

7.1 MULTI-MODAL TRAVEL ACTIVITY CONCEPT & ARCHITECTURE
-------------------------------------------------------------------------------
A single Travel Activity log (e.g. "Global Sales Summit Q1" or "Employee Monthly Commute")
can contain multiple itemized Trips / Segments across LAND, AIR, and SEA transport modes.

Parent Entity: `TravelActivity`
Child Entity:  `TravelActivityTrip` (ordered list of trips within a journey)

Categories Supported:
- `BUSINESS_TRAVEL` (Scope 3 Category 6)
- `EMPLOYEE_COMMUTING` (Scope 3 Category 7)

Transport Modes Supported per Trip:
1. `LAND`: Requires `car_type_id`, `fuel_type` (diesel, petrol, hybrid, cng, lpg, unknown, phev, bev, general).
2. `AIR`: Requires `haul_type` (Domestic, Short-haul, Long-haul, International), `cabin_class` (Average passenger, Economy class, Premium economy class, Business class, First class), `include_rf` (boolean).
3. `SEA`: Requires `passenger_type` (Foot passenger, Car passenger, Average (all passenger)).

Gas Factor Breakdown calculated per trip and aggregated at parent activity level:
- total_kg_co2e, total_t_co2e
- total_kg_co2, total_t_co2
- total_kg_ch4, total_t_ch4
- total_kg_n2o, total_t_n2o
- Transport Mode Breakdowns: `land_t_co2e`, `air_t_co2e`, `sea_t_co2e`

9. SUMMARY OF COMMON ERROR CODES & EDGE CASES
===============================================================================

HTTP Status | Error Code                              | Reason / Resolution
-------------------------------------------------------------------------------
400 Bad Req | SPEND_DATE_YEAR_MISMATCH               | `spend_date.year` does not match `spend_year`.
400 Bad Req | INVALID_SPEND_YEAR                      | `spend_year` is outside allowed range (2020-2025).
400 Bad Req | SCOPE3_ACTIVITY_IMMUTABLE               | Entry is in state "VERIFIED". Use /amend instead.
400 Bad Req | INVALID_WASTE_TREATMENT_METHOD          | Method not supported/active for selected waste type.
400 Bad Req | INVALID_WASTE_QUANTITY                  | Quantity generated in tonnes is <= 0.
400 Bad Req | HTTP_400_BAD_REQUEST                    | Missing required mode trip parameter (e.g. car_type_id for LAND).
404 Not Fnd | REPORTING_PERIOD_NOT_FOUND              | `reporting_period_id` invalid or doesn't belong to tenant.
404 Not Fnd | CAR_TYPE_NOT_FOUND                      | CarType UUID invalid or not found.
404 Not Fnd | LAND_TRAVEL_FACTOR_NOT_FOUND            | Land travel emission factor not found for selection.
404 Not Fnd | AIR_TRAVEL_FACTOR_NOT_FOUND             | Flight factor not found for haul_type and cabin_class.
404 Not Fnd | SEA_TRAVEL_FACTOR_NOT_FOUND             | Ferry factor not found for passenger_type.
404 Not Fnd | TRAVEL_ACTIVITY_NOT_FOUND               | Travel activity ID invalid or not found.
422 Unproc  | INVALID_SPEND_AMOUNT                    | Spend amount in INR is <= 0.
422 Unproc  | UNPROCESSABLE_ENTITY                    | Input validation failed (e.g. distance <= 0).
